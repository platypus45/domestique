## Migration order (suite green at every wave)

1. **Extract data (no behaviour):** `science.py` from tp constants + config thresholds; re-export names from tp/app so tests importing `tp.TSS_PER_HOUR` still pass; delete the three app/dashboard zone copies against one `/api/science` endpoint. Add a test that the JS table equals the Python table.
2. **`model.py` + codec:** move dataclasses and `*_from_dict` out of tp with `from model import *` in tp (re-export keeps `tp.PlannedSession` identity for 60 `monkeypatch.setattr(tp` uses); fold `SESSION_FIELDS_LOCKED` into the codec; add `__post_init__`. Retires HTTP-11's app-side sites (6 `tp.PlannedSession(` constructors + 20 hand dicts) and `_field`/`_g` adapters once dicts stop crossing the boundary.
3. **`library.py`:** move `_scan_zwo_for_library`/`_np_fraction_from_samples` (app) and matching (tp 4495-5722); deletes `tp.py:6457 import app` and the byte-identical duplicate. Breaks cycle app↔tp.
4. **`plan_store.py` (Step 7):** one path derivation injected from `ProfileManager`; replace 21 handler `atomic_write_plan` sites with `store.update(fn)`; `icu_calendar_push._load_plan` and `paths._plan_dir` read the store. Breaks pm↔tp, app↔icu_calendar_push.
5. **`loads.py`:** move CTL/ACWR math out of `ride_storage`/`training`; breaks db↔training, power_curve↔ride_storage.
6. **Planner package (Step 6):** `week.py` absorbs `plan_week/propose_week` so `week_plan` stops importing tp; entry points become compositions; ICU push/markdown/`main` leave tp. Install the seal in src.
7. **Services + routes split:** move handler bodies >80 lines to service functions with the same names (http.md §2 table), then split `app.py` into `routes/*` with `app.py` as the include shim so 187 test files importing `app` keep working; GETs stop writing (D8) and stop kicking sync.
8. **Frontend:** introduce `store.js` (`getResource('/api/…')` memoised per home load), replace the 7/5/3 duplicate fetches, then split tabs into files served from `static/app/`. No framework.
